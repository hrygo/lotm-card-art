# 固定几何与准入合同

## 结构基线

一套品质框具有唯一母框、原生坐标、净化后结构alpha、材质区域和锚点。原图、基线、区域配置、处理程序分别绑定版本与哈希。净化alpha改变了基线时，登记新版本，不把它表述成与原图alpha完全相同。

固定对象包括外轮廓、内窗口、肩部、侧轨、定位纹样、姓名牌与品质片。分区来自母框，不由每个变体独立推导。区域结构蒙版与自动语义分层是两种不同能力。

当前五档品质读取config/quality-color-tokens.json。纹理色相流动、宝石反射/亮点是允许的材质变化，不能用整层RGB相等误拒；定位结构、宝石槽和层序仍固定。色彩层次与切面亮度采用视觉验收，五档主色保持可辨。以下工具能力说明仍针对旧四档实现，不代表新色表已接入。

## 两种派生路径

| 路径 | 结构依据 | 准入条件 |
| --- | --- | --- |
| 确定性材质调色 | 同一母框原像素位置，固定区域只变RGB | 当前处理链可重建，实际alpha与预期相同；内部实心像素匹配确定性材质结果；最终位置一致 |
| Agentic材质或整框候选 | 生成内容本身不提供位置保证 | 独立结构层、允许材质区域及几何证据可核验；整框仅裁进外轮廓不合格 |

第一条是当前愚者专用工具的实现路径。第二条不是当前工具已实现的任意图像准入能力；缺少相应证据的生成变体保持候选/blocked，不通过填写pass或套用第一条检查放行。

## 结构化输入

以下字段属于生产记录合同，不自动成为现有CLI参数；不向旧task schema注入未支持字段。

| 输入 | 约束 |
| --- | --- |
| task_id、pathway_id、quality或sequence列表 | 范围明确，每个序列仅出现一次 |
| master、geometry_version | 路径、实际哈希、原图与基线区别、批准范围 |
| canvas、transform | 尺寸、坐标方向、统一采样；变体没有独立配准权限 |
| regions/components | 固定区域或组件id、边界、层序、蒙版/实现来源及摘要 |
| anchors、protected_regions | 唯一圣徽中心、姓名内区、品质片、插画和顶部留空 |
| material_intent | 色调、局部品质信号、对比与反射表现；不得另画定位构件 |
| references、limits | 生图时的真实附件与尝试上限；程序派生如实记录算法，不伪造生图调用 |

## 检查口径

- 同一原生坐标比较结构；画布、alpha、构件位置与固定变换的差异为零。输出统一重采样，不逐品质移动、缩放、旋转或扭曲。
- 材质图不与原母框RGB逐像素相等比较；确定性路径与“执行同一材质算法后的预期像素”比较，允许品质差异并发现内部像素被替换或移动。
- 每份证据绑定实际使用的输入、程序和输出。不以未参与装配的正确蒙版证明成图正确；相关内容变化后重新生成与检查。
- 光晕和接触阴影独立于结构，不越过保护区，不作为字形/徽章居中的测量边界。
- 几何正确不证明视觉无错觉。材质分区接缝、过曝、假轮廓、品质混淆、净底残色另行视觉检查。

## 当前实现与边界

`tools/render/foolkit.swift gate`校验清单记录的输入、输出、程序摘要，四框实际alpha、实心区域RGB以及十张最终合成alpha/位置。它针对该工具的确定性链，不是通用视觉识别、自动语义分层或任意图像的全像素认证。半透明边缘不由实心RGB比较覆盖。

当前工具导出五份固定区域蒙版，没有实现通用逐组件语义诊断通道或几何差异图系统。原生反例覆盖结构像素变化、材质alpha不变、文件篡改与覆盖拒绝。测试结果与当前版本从执行记录核对，不在Skill固化计数。

## 拒收与状态

来源不匹配、结构差异、错误位置、透明失败或已知视觉破损均阻止相应版本成为可用交付。无法核验的项是unknown/not-run，不是0或pass。几何、净底、视觉观察、用户批准、正式发布分别记录。

study允许诚实交付待审材质方案，不允许把已知工程破损包装成“待艺术审核”。需要修改母框结构时建立新基线；旧漂移变体只保留为历史参考，不参与后续装配。
