# apps/ 目录工作约定

## 范围

本目录承载《诡秘之主》卡牌画册的客户端代码与运行说明。它是应用施工范围，不改变仓库根目录关于卡牌内容、正典核验和美术交付的质量门槛。

## 数据边界

- `LotmCardStudio` 当前使用隔离的示意内容；示意内容不得冒充已核验正典或正式卡牌。
- `card_id`、`character_id`、内容状态和叙事审批状态保持分离；不得用 UI 展示状态代替事实核验。
- SpeechRail 只负责本机语音合成接入；服务不可用时必须保留文字稿阅读路径，不得伪造播放成功。

## UI 施工约定

- 详情页的主卡面、语义面板和故事抽屉使用正常布局流，避免依赖固定高度叠放导致容器重叠。
- 新增交互优先补领域/视图模型测试，再修改界面；完成前至少运行 `swift test` 和对应的 `.app` 构建脚本。
- 不在客户端源码中写入令牌、私钥或真实人物隐私资料。
