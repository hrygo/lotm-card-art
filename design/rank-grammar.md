# 序列递进：改变存在方式，不只是提升装饰量

序列数字只用于导航。下表是与 `art-bible.md` 一致的美术观察轴，不是关于所有途径的统一原著结论；“人性/神性”描述画面叙事权重，不是道德评价或能力数值。

| 观察段 | 设计问题 | 应避免 |
|---|---|---|
| 9–8 | 人物如何以技能、行为和具体处境与世界发生联系？ | 在低序列预支神级效果，或以抽象氛围遮掉人的尺度 |
| 7–5 | 人性与非凡性如何同时存在，主体/身份/事件关系怎样变复杂？ | 硬套所有途径都变脸/异化，或抹掉人物行为 |
| 4–3 | 超自然性质如何重组环境或身体尺度？ | 用任意畸形代替原著能力 |
| 2–1 | 存在与领域、条件、群体或概念是什么关系？ | 所有天使都加羽翼与金光 |
| 0 | 哪种核心关系统摄了整个画面？ | 每个神都坐同一把巨大王座 |

递进的七个调节轴：主体占比、空间层次、因果可见性、材料变换、边框介入、时间组织、文字语气。设计记录另外明确人类锚点、神性压力和抽象载体，避免把“更高序列”退化成更大的装饰量。
不要求七轴同时单调增长；留白更多、动作更少、空间更安静，也可能比装饰堆积更有层次。
每条途径完成研究后，为十个序列各写一句“不可被相邻卡替换的主事件”，逐对排除重复。
不把愚者的面具/帷幕/戏剧递进模板拷贝到其余21条途径。
