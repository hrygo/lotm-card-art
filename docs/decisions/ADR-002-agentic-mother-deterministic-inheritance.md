# ADR-002：Agentic 创作母版，确定性继承几何并局部铭刻

## Status

Proposed

## Date

2026-09-14

## Context

愚者途径需要从一张高辨识度边框母版派生五档品质，再形成十个序列框。Agentic 对材质、宝石、浮雕和神秘学装饰具有明显创造力，但完整图像重绘会改变外轮廓、锚点、文字区和 alpha。此前低序列到中序列的全框迁移测试保留了大轮廓，却产生 RGB 无 alpha、烘焙棋盘格和局部几何误差，不能满足生产级零漂移要求。

同时，愚者侧铭文需要保留初版帷幕柱体的艺术语言，姓名区又必须直接铭刻在既有材质表面，不能新增底色或遮挡宝石。因此需要重新划分 Agentic 创作和确定性合成的职责。

## Decision

采用“Agentic 美术创造 + 程序结构继承”的混合生产架构：

1. Agentic 生成愚者途径母版候选，提出左侧途径身份、EmblemDock、右侧留白、姓名表面和宝石槽的视觉语言。
2. 经净底、分区和几何测量后冻结生产 `FrameCore`；外轮廓、锚点、保护域、姓名面和宝石位由程序持有。
3. Agentic 分别派生五档材质与宝石候选；通过审查的材质语言只能在固定区域内落版，不得改变母版几何。
4. Agentic 对每个序列做右侧局部铭刻研究；程序锁定精确字符、实际墨框、方向、位置、alpha 和最终合成。
5. 使用五档到十序列的一对多映射生成十个序列框，不生成 50 个无意义的品质/序列组合。

结构所有权如下：

| 责任 | 所有者 |
| --- | --- |
| 外轮廓、立柱、插画窗口、姓名面、宝石位 | `FrameCore` |
| 圣徽嵌孔、暗腔、承托和前缘 | `EmblemDock` |
| 途径形体、序列数字 | `EmblemAsset` |
| 品质纹理、宝石材质 | `QualityMaterial` |
| 精确序列字符与姓名字符 | `TextEngraving` |
| 定位、遮挡、alpha、输出和门禁 | `Composer` |

## Alternatives Considered

### A. 每个阶段让 Agentic 直接输出完整最终框

拒绝。创造力最高，但会把几何、文字、alpha 和承托一起重绘；此前实测已经证明它无法保证零漂移和真实透明交付。

### B. 完全程序化生成母版、五档和铭刻

拒绝作为主要路径。几何稳定，但会牺牲愚者途径需要的神秘学材质、帷幕柱体、宝石光学和铭文艺术创造力。

### C. Agentic 负责局部美术，程序负责结构和精确字符

接受。它保留 Agentic 在真正需要审美判断的部分的优势，同时把最容易返工的几何、文字、alpha 和组合关系变成可测量合同。Agentic 的完整重绘仍可保留为风格研究，但不拥有生产结构。

## Consequences

### 正面影响

- 母版只需审一次，五档和十序列可以复用固定结构；
- 五档品质可以有明显的材料和宝石差异，而不必不断增加装饰；
- 右侧序列铭刻可以保留愚者初版侧柱的艺术语言；
- 姓名区、宝石区和圣徽区可以独立返修，不互相覆盖；
- 任何漂移、伪文字、棋盘格或重复底板都能在阶段门禁中被拒绝。

### 成本与限制

- Agentic 候选不能直接作为母版，必须经过净底、分区和测量；
- 每一档材质研究和每一个序列铭刻都需要真实调用记录；
- 需要实现母版接口、局部差分和序列文字门禁；
- 用户视觉批准仍是独立步骤，机器通过不会自动完成批准。

## Verification boundary

本 ADR 被接受后，只授权按新版流水线实现和测试，不代表愚者母版、五档边框或十序列框已经生成或批准。每个阶段必须保留真实输入、输出摘要、门禁结果和视觉状态。
