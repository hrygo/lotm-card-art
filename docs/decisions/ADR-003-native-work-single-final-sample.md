# ADR-003：原生画布工作，最终整卡一次采样到 2K

## Status

Accepted

## Date

2026-09-14

## Supersedes

ADR-002 中“中间阶段先固定到标准 2K、再进行局部铭刻和装配”的生产假设。

## Context

当前 Agentic 输出主要是 `1024×1536 RGB` 的完整视觉图。旧流程把母版、五档、无铭文序列框和局部铭刻逐步转成 `2048×3072`，再在 2K 画布上裁切、回填和继续合成。实测表明，这会带来三个问题：

1. 每次放大和 PNG 往返都会消耗半透明边缘与细小材质细节；
2. 局部裁切/回填会把 Agentic 原图变成复刻对象，容易出现接缝、截字、双边缘和位置漂移；
3. 2K 中间层让后续 Agentic 看到的是被工程处理过的图，而不是原始设计意图。

愚者途径已经明确采用 Agentic 完整图作为视觉基准，因此应把 2K 限定为最终交付尺寸，而不是中间工作坐标系。

## Decision

采用“原生工作画布 + 完整 Agentic 生成 + 最终整幅一次采样”的生产工艺：

1. 母版、五档品质、十个序列框、主体、背景、姓名和其他中间物料均保持各自 Agentic 实际原生尺寸；不提前转 2K。
2. 序列数字和序列名称在 Agentic 完整序列框中同图完成。程序只登记结构化元数据、摘要和诊断信息，不把失败的局部切片贴回另一张底框。
3. 主体与背景优先由 Agentic 生成完整卡候选；若保存分层，分层仍在原生完整画布上完成一次合成，不在 2K 上逐层拼接。
4. 用户验收的是原生完整卡。验收通过后，以同一份 `FinalCard-Native` 为源，整幅、等比例、无裁切地一次生成 `2048×3072` 标准交付；`4096×6144` 收藏版也从同一原生源直接生成，不经过 2K。
5. 每个最终 manifest 必须记录原生源摘要、最终摘要、源/目标尺寸、前置裁切次数、中间 2K 次数和最终采样次数。

## Alternatives Considered

### A. 每个中间层先转 2K，再进行后续合成

拒绝。会重复采样，增加边缘量化、切割接缝和“为合成而合成”的返工；也违背 Agentic 完整图为视觉权威的决定。

### B. 每个阶段维持完整原生画布，最终一次转 2K

接受。保留原始设计信息，避免中间裁切和多次采样；最终交付链简单、可审计，2K/4K 都直接绑定同一原生源。

### C. 先转 2K，最终再用 2K 转 4K

拒绝。会把标准交付的后处理误当成收藏母版源，造成两次放大；收藏版必须从已验收原生完整卡直接生成。

## Consequences

### 正面影响

- Agentic 生成的完整构图、材质、文字和边框关系不会被中间裁切破坏；
- 返修回到原生完整卡，避免在低分辨率成品上补字、修边和抠层；
- 2K/4K 的差异只存在于最终交付，不再污染中间资产；
- 每张卡可以清楚回答“原生源是什么、最终采样发生几次、是否裁切”。

### 成本与限制

- 中间预览可能仍是 `1024×1536`，不能用像素数冒称 2K；
- 需要 Agentic 在完整画布上一次解决边框、序列名和主体关系，不能依赖后期局部修补；
- 最终采样后的文件视为冻结交付物，任何文字或结构错误必须回到原生源修复；
- 历史 2K 中间产物保留用于追溯，但不再作为新生产输入。

## Verification boundary

本 ADR 改变工作分辨率和采样顺序，不自动批准现有图像。新的最终产物必须同时通过原生视觉验收、文字/事实验收、整幅最终采样检查和正式 release 门禁。
