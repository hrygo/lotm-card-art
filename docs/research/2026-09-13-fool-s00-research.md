# 愚者途径 · 序列 0「愚者」研究与卡面转译

研究日期：2026-09-13  
研究范围：`lotm-volume-1-zh` 的 `lotm.fool.s00`  研究状态：`evidence-updated / mixed verification`，不是正式设定批准，也不是可发布卡面。

## 1. 结论先行

本卡应被定义为「愚者途径的序列 0 正式序列卡」：

- 卡牌名称是「愚者」；「真神」是跨途径层级标签，不是特殊事件、异画或卡牌类型。
- 9–0 是连续的序列编号。项目目前采用的层级解释为：9–8 低序列，7–5 中序列，4–3 半神/圣者，2–1 天使，0 真神。序列 1 在部分语境中可称大天使；「天使之王」是超越序列 1 但尚未成为真神的状态或称谓，不应写成序列编号。
- 序列 0 的位阶、愚者途径 9–0 名称、序列 0 配方、晋升仪式和三项能力已经得到当前中文官方设定集/章节片段支持；扮演没有独立的序列 0 守则，限制仍是有范围的资料缺口。因此，本卡暂不进入 `approved`，但可以从研究阶段推进到视觉候选。
- 六维现在是“可审查的研究转译”：身份、能力、魔药、晋升为 `supported`；扮演为明确标记的 `interpretation`；限制为明确范围的 `knowledge_gap`。它们不是六格面板，也不是用气氛代替事实。
- 故事采用以克莱恩经历为基础的原创/解释性叙事，6 条文案已由用户逐字批准；视觉仍是候选稿，不因叙事批准而自动变成正式卡面。

## 2. 研究方法与证据等级

本次优先使用官方起点中文页面、官方世界手册和官方 WebNovel 英文译本作为可访问的一手定位材料；英文译本仍只作补充定位。通过官方《诡秘之主》设定集页面的可见正文，本轮取得了愚者途径 9–0 的中文名称、序列 0 配方、仪式和三项能力；通过起点第一百零一章片段再次核对“序列0等于真神”。VIP章节正文仍未完整取得，非官方镜像只保留为历史检索线索，不复制正文。

另外，通过官方《诡秘之主》设定集的“力量体系/神之途径”页面视觉读取到跨途径层级概述：22条途径、序列9至0、序列4以上半神、序列2以上天使，以及序列0成就真神。它补强了项目的跨途径层级配置，但没有替代愚者途径的专属正文核验。[起点官方设定集](https://h5.if.qidian.com/h5/workSet/main?albumId=131&bookId=1010868264)

证据标记：

- `supported`：当前工作范围内有可核验的一手证据，且已满足项目的来源与审核要求。
- `partial`：只取得页面片段、章节标题或跨作品范围的材料，能够限制创作方向，但不能支撑完整断言。
- `lead`：可用于下一轮核验的候选设定；不能作为正式卡面事实。
- `interpretation`：基于已知场景的原创设计转译，不冒充原著固定术语或规则。
- `knowledge_gap`：限定检索范围后仍缺证；不等于“原著不存在”或“原著未披露”。

## 3. 已确认的层级框架

官方《诡秘世界研究手册》的 Paths of the Divine 页面用于交叉核对 22 条神性途径、9–0 序列和高序列层级。页面主体依赖脚本，项目因此将其保留为 `partial`，但它足以支持项目层级模型的范围校对：[官方层级手册](https://www.lomworld.com/handbook/en?categoryId=3)。

项目内的稳定解释见 `config/sequence-hierarchy.json`：

| 序列 | 项目层级标签 | 设计上的含义 | 不能混淆为 |
| --- | --- | --- | --- |
| 9–8 | 低序列 | 人类尺度的非凡者起点 | 半神或天使 |
| 7–5 | 中序列 | 第五纪常见的中序列阶段 | 圣者/天使 |
| 4–3 | 半神，通常为圣者 | 进入神性与仪式性显著增强的阶段 | 真神 |
| 2–1 | 天使；序列1在部分语境中可称大天使 | 高序列人格与权柄承载者 | 序列0 |
| 非编号状态 | 天使之王 | 广义上是超越序列1、尚未成神的状态；狭义另有历史称谓 | 一个固定的序列编号 |
| 0 | 真神 | 对应途径的神位 | 特殊事件或卡背 |

起点官方设定集的中文表述使用“序列4以上为半神、序列2以上为天使”的范围式说法；项目显示层采用更具体的标签覆盖：序列4–3显示圣者、序列2–1显示天使、序列0显示真神。这样既保留“半神”作为高序列总称，也避免把序列0误显示成天使或把“天使之王”误当序列编号。

这里的“真神”只负责告诉用户这张序列卡处于 0 阶位；卡面主标题仍是「愚者」。官方站点也将 The Fool 与编号 0、愚者故事线关联，可作英文定位参考：[官方世界概览](https://lomworld.com/en/lom)。

## 4. 愚者序列 0 的事实研究

### 4.1 身份

工作标签：`愚者途径 / 序列 0 / 愚者 / 真神`。

当前状态：途径名、序列 0 名称和位阶关系为 `verified`。官方设定集的“4.1 愚者途径”页面直接列出 9–0 的中文名称及序列 0 条目；起点第一百零一章片段支持序列 0 与真神的中文位阶关系。[起点第一百零一章“可能”](https://www.qidian.com/chapter/1010868264/424607198/)、[起点官方设定集](https://h5.if.qidian.com/h5/workSet/main?albumId=131&bookId=1010868264)

### 4.2 扮演

官方设定集的“扮演法”部分说明应从魔药名称提取核心象征和具体意象；但在序列 0「愚者」条目中没有单列一套扮演守则。因此，当前卡面采用一个明确标记为 `interpretation` 的行为提案：

> 在身份与关系不断错位时，仍保持对自身的辨认；让“被看见的角色”和“真正承担后果的主体”同时存在。

这不是把“神秘”“欺骗”或“装傻”硬写成固定口诀。它只为视觉提供行为事件：在巨大非人权柄场中，身份残影被历史金线折叠、擦除又保留，提示“被看见的角色”和“真正承担后果的主体”仍有关联。该解释已按官方一般扮演法和序列 0 能力范围审查，但不冒称原著固定原则；以后出现更明确的中文条目时，应根据原文改写或撤回。

### 4.3 能力

官方中文设定集在“序列0：愚者”条目中直接列出三项能力：

1. `愚弄`：可影响认知与环境，也可作用于时间并分割前后相邻时刻的自身；这是古代学者相关能力的深化。
2. `重组`：可将自身与星空中某颗恒星的概念嫁接。
3. `诡秘之境`：形成完整的神国。

官方英文剧情片段对历史投影、愚者卡状态变化和 `Fooling` 的定位可作叙事补强：[Fooling](https://www.webnovel.com/book/11022733006234505/fooling_45129713886230191)、[Stipulated Rules](https://www.webnovel.com/book/11022733006234505/stipulated-rules_47290690459196478)、[Madness](https://www.webnovel.com/book/11022733006234505/%22madness%22_47290706565332404)。本卡将“历史相邻状态被金线折叠”作为一个主事件，不把三项能力扩写为未列出的全能机制。

### 4.4 魔药

官方中文设定集列出的摘要：主材料为愚者唯一性与自身之外剩余两份诡秘侍者非凡特性；辅助条件为掌控至少四分之一个历史迷雾。

证据状态：`supported / primary_chinese`。官方设定集的“4.1 愚者途径 > 序列0：愚者 > 魔药配方”直接列出主材料和辅助条件；官方英文第 1291 章与旧二手索引只保留为章节交叉定位：[官方 Two Rituals 定位](https://www.webnovel.com/book/11022733006234505/two-rituals_45148053144913263)、[起点官方设定集](https://h5.if.qidian.com/h5/workSet/main?albumId=131&bookId=1010868264)。

卡面仍采用低文字密度摘要，不复制原著段落，不补造材料外观、颜色、服用动作或容器；“支持”表示事实已由当前官方设定集页面覆盖，不表示已完成视觉批准。

### 4.5 晋升

官方中文设定集列出的晋升仪式：愚弄一次时间、历史或者命运。

证据状态：`supported / primary_chinese`。序列 0 的通用真神层级条件不能替代愚者途径自己的仪式；卡面继续把两层分开：[官方 Two Rituals 定位](https://www.webnovel.com/book/11022733006234505/two-rituals_45148053144913263)、[起点官方设定集](https://h5.if.qidian.com/h5/workSet/main?albumId=131&bookId=1010868264)。

卡面把它转译为“边框/门槛/被回收的时间线”这一结构，不画固定祭坛、固定祷词或额外步骤图。

### 4.6 限制

本次资料没有形成一份可直接核验的“序列 0 愚者完整限制清单”。这是一条有范围的 `knowledge_gap`：截至 2026-09-13，官方中文设定集的序列0条目列出了配方、仪式和能力，但没有独立限制小节；官方英文页面片段、世界手册和二手线索也没有补成完整限制表。这不宣称原著不存在限制。

几个容易误读的方向暂不纳入正式限制：

- 第 1352 章关于诡秘侍者魔药导致自我与灵界信息解体的片段，首先属于序列 1 的晋升/失控场景，不能未经证据转写成序列 0 的固定副作用：[Attendant of Mysteries](https://www.webnovel.com/book/11022733006234505/attendant-of-mysteries_46571607958807867)。
- 第 1389 章关于愚者将要沉睡的叙事，是特定剧情阶段与天外战争/末日状态的定位，不等于每一张愚者原型卡都必须有“沉睡”限制：[The Fool's Commission](https://www.webnovel.com/book/11022733006234505/the_fool%27s_commission_47290739851329152)。
- 敌人的克制、场景失败或画面裂纹不能自动升级为规则性限制。

卡面只保留一条“金线在帷幕处收束并停止”的边界提案，并把它标为研究中的视觉占位；正式限制文案必须等待中文证据。

## 6. 叙事与声音方案

故事采用以克莱恩经历为主线、但不复述原著段落的原创/解释性叙事。应用中的三章围绕“帷幕接缝”“被折叠的现在”“沉睡之前”组织，具体文本在 `apps/LotmCardStudio/Sources/LotmCardStudioFeatures/DemoContent.swift`，6 条 `NarrativeLine` 均通过内容摘要标记为 `approved`。当前已完成 `render-v003` 权柄优先画面候选；叙事批准与视觉批准仍然分开。

声音使用 SpeechRail 系统音色 `uncle_fu`，其公开描述为成熟稳重、低沉醇厚、语速平稳的中文男声；不使用真实演员或未经许可的角色音色模仿。6 个 WAV 已由本机 SpeechRail `2.5.1` 生成并写入 `artifacts/lotm.fool.s00/audio-v001/`，同时复制到应用资源目录。短台词单次生成，三章故事按自然句切分生成后合并；参数、摘要和 SHA-256 见同目录 `generation.md`。

自定义 voice design 本轮未注册：设计接口返回认证错误，未继续创建持久化音色；因此 `uncle_fu` 应明确视为系统音色，而非 Klein 专属声线。

音频进入生产的前置条件：

1. 人工确认故事、问候语和口头禅的逐字文案。**已完成：6 条文案已获用户批准。**
2. 中文原著核验完成，或明确接受原创/解释性文本而不将其标为正典。
3. SpeechRail 完成真实服务健康检查和一次可回放的合成验证。**已完成：6 个资源均返回有效 RIFF/WAVE。**
4. 生成文件、参数、哈希和试听审核记录落盘；失败时保留文字稿，不显示伪成功。**已完成生成记录；视觉 release 仍待后续。**
