## 1. 本次补充结论

首版神话生物图把安提哥努斯画成了“人形核心 + 石质结构 + 灵性丝线”，虽然承接了第四纪“半个愚者”的高位压力，却没有把魔狼物种作为第一识别线索。

本次修正采用以下顺序：

1. **魔狼是主体识别锚点**：画面首先读到大型、四足、单首、长吻、尖耳、狼毛和尾部完整的魔狼；不再以人形站姿作为主体。
2. **半个愚者是状态层**：透明灵性丝线、薄石质板片和胸口不完整接合环只作为同一身体上的高位残留，不能吞没魔狼轮廓。
3. **安提哥努斯是人物而非弗雷格拉复刻**：保留沉静、具人性痕迹的目光、黑色仪式布片、山顶宫殿和安静国家灯火；不使用原初灾厄狼神的世界末日尺度。
4. **不冻结个人神话形态解剖**：项目当前仍把安提哥努斯的个人高位神话生物构成，以及魔狼形态与灵之虫形态的精确层级关系标为 `mixed / not-frozen`。本图是候选艺术解释。

## 2. 证据与边界

### 2.1 已登记的一手译本线索

[第 1374 章 Trojan Horse of Destiny](https://www.webnovel.com/book/lord-of-mysteries_11022733006234505/trojan-horse-of-destiny_46571612253775201) 将安提哥努斯置于“半个愚者”和巨大石椅的场景中，并描述他有浓密的黑色狼状鬃毛。这支持“狼性外观必须进入主视觉”的转译方向，但该英文页面本身不单独冻结安提哥努斯完整个人神话形态的解剖细节。

### 2.2 项目内既有研究的可复用边界

- `2026-09-14-antigonus-card-materials.md` 已登记安提哥努斯的第四纪“半个愚者”状态、夜之国、霍纳奇斯宫殿、唯一性、精神烙印和天尊意志关系。
- 该资料包允许身份表达采用人形或狼形，但要求不要把人物与弗雷格拉、序列 0「愚者」或其他愚者途径人物混为一谈。
- `pathways/fool/canon.json` 中的乌黯魔狼配方材料是途径级魔药研究，不自动等于安提哥努斯个人的服药记录；本补充不把配方材料画成可操作的炼制步骤。
- “魔狼为安提哥努斯物种锚点”是本次用户校正后的视觉事实输入；关于精确个人神话形态，仍以中文底本逐项核验为准。

## 3. v2 视觉转译方案

### 3.1 主体

一头大型但不是弗雷格拉式原初神体的四足魔狼，完整露出狼首、四腿和尾部。黑色至炭灰色狼毛承担主体材质，眼神保持安提哥努斯的克制与疲惫，不使用人脸替代狼首。

### 3.2 高位状态

少量透明灵性丝线沿鬃毛、脊背和后腿交织，薄石质板片贴合在身体外缘；它们与狼体连续，不形成独立幽灵、触手群或秘偶操控线。胸口的不完整环表达唯一性容纳后的未完成接合，不是官方徽记或可读符号。

### 3.3 故事环境

主体位于霍纳奇斯山顶古老宫殿/石椅前，远处保留小而安静的国家灯火，天空右侧有狭窄的历史裂缝。环境把“魔狼本体—半个愚者状态—夜之国情感锚点—封存与限制”串成一个连续事件。

### 3.4 消歧与禁止

- 不画第二只狼，不画弗雷格拉的原初灾厄规模。
- 不画完整灰雾王座、源堡、完整序列 0 愚者神国或终局权柄。
- 不添加人类躯干、人类四肢、多头多面、巨眼、角、翼、触手群、秘偶、木偶线、卡框、序列数字、姓名、途径徽记、可读文字或水印。
