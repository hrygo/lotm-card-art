## 4. 六维原材料

### 4.1 身份 Identity

**事实输入**

- 卡面身份应明确写成：`愚者先生`、`序列 0 · 愚者`、`愚者途径`；「真神」是层级元数据，不写成特殊事件。
- 愚者先生是克莱恩的神格身份切片，是身份链的收束，不是与克莱恩无关的原生神祇。
- 公开身份为灰雾之上的神秘存在、塔罗会首领、愚者教会神祇；这属于身份层的公开定位。

**原材料载体**

- 确定性文字层：姓名、途径、序列数字、序列名称与真神层级；不交给生图模型猜字。
- 主视觉：约 80% 为非人权柄与象征（金线、帷幕、神国与星体概念），人形残影不超过 20%，仅作尺度参照。
- 身份关系：以「被看见的角色」与「承担后果的主体」之间的折叠张力表达，而不是神格肖像。

**误读阻断**

- 不把「愚者先生」做成新的序列 0 非凡者或独立本体角色；
- 不把序列 0 权柄画成王座、神像或可辨认人像；
- 不把途径名「愚者」误读成特殊事件、卡背类型或天使之王替代称谓；
- 不用克莱恩早期身份（廷根书房、灵摆、占卜桌）直接冒充神格阶段。

### 4.2 扮演 Acting

**序列级研究输入（`interpretation`）**

- `fool.sequence0.acting_candidate` 是明确标注的原创转译：在身份、关系与历史表面不断错位时仍保持对自身的辨认，让「被看见的角色」与「真正承担后果的主体」同时存在。
- 官方设定集的「扮演法」说明可从魔药名称提取象征，但序列 0 条目没有单列扮演守则；该转译不冒称原著固定口诀。

**愚者先生身份的解释性转译**

- 他让塔罗会成员相信灰雾之上有一位古老神祇，把恐惧、愿望与秘密放上长桌，自己躲在神座之后观察每个人的选择。
- 名字起初是安全距离，后来成为责任：当有人呼唤「愚者先生」，这个名字就要求他对结果负责。
- 扮演的核心不是「装神秘」，而是在成了神之后仍保持对自身的辨认。

**后续卡面回读**

- 主画面对应巨大非人权柄场中一个微小、无面、近乎被擦除的身份残影；
- 以折叠位置和连续金线表达「错位中的自我保持」，不做人物站姿或表情表演；
- 不能用灰雾、王座或神秘感替代具体行为线索。

### 4.3 能力 Abilities

**代表能力输入（均为 `verified`）**

1. `愚弄`：可影响认知与环境，也可作用于时间并分割前后相邻时刻的自身；是古代学者相关能力的深化。
2. `重组`：可将自身与星空中某颗恒星的概念嫁接。
3. `诡秘之境`：形成完整的神国。

**能力边界**

- 主视觉只选择「愚弄历史造成相邻状态折叠」作为可回读主事件，不把三项能力扩写为未列出的全能机制。
- 「重组」不画成具名天体或具体角色；「诡秘之境」的神国是能力定位，不等同于固定建筑外观或通用王座。
- 三项能力摘要不等于全部作用条件；正式排版前保持短摘要与主事件分离。

**明确排除**

- 历史投影、诡秘之主层次、福生玄黄天尊意志等，须回到对应序列或本体的证据，不能提前并入序列 0 卡面主事件；
- 序列 1 诡秘侍者的失控/解体场景不能冒充序列 0 能力；
- 队友或敌人的克制、场景失败不能升级为权柄机制。

### 4.4 魔药 Potion

路径级配方为 `verified`，应引用 `fool.sequence0.potion_formula`，不在本卡重新复制一份无来源配方。

**研究摘要**

- 主材料：愚者唯一性，以及自身之外剩余两份诡秘侍者非凡特性。
- 辅助条件：掌控至少四分之一个历史迷雾。

**卡面原材料建议**

- 只保留低文字密度摘要与诚实档案区；不补造材料外观、颜色、服用动作或容器，不复制原著段落。
- 主视觉不放拟人化药瓶；黑色药瓶不得被误当成序列 0 材料。
- 魔药线索不能压过权柄/身份主事件。

### 4.5 晋升 Advancement

**当前研究结论**

- 官方中文设定集给出的晋升仪式：愚弄一次时间、历史或者命运（`fool.sequence0.ascension_ritual`，`verified`）。
- 序列 0 的通用真神层级条件不能替代愚者途径自己的仪式；两层在卡面分开记录。

**人物卡处理**

- 边框转译为「被跨越又被收束的门槛」这一结构，不画固定祭坛、祭品、祷词或完整步骤图。
- 不把「进入序列 0」与愚者先生随后进入沉睡的剧情状态混为一谈。

### 4.6 限制 Limitation

**事实/研究边界**

- 截至研究日期，可访问的官方中文设定集序列 0 条目列出了配方、仪式与能力，但没有独立限制小节；合并登记的 `fool.sequence0.limitations_gap` 是有范围的 `knowledge_gap`，不宣称原著不存在限制。
- 下列方向暂不纳入正式限制：第 1352 章属序列 1 的失控/解体场景；第 1389 章的沉睡属特定剧情阶段；敌人克制、场景失败与画面裂纹都不自动等于规则性限制。
- 福生玄黄天尊意志、聚合本能与锚的影响属角色资料层，不能未经底本核验转写为序列 0 固定副作用。

**视觉边界**

- 只保留「金线在帷幕处收束并停止」的边界提案，标为研究中的视觉占位；
- 正式限制文案必须等待中文一手证据，撤回无依据的视觉限制占位。

## 5. 单一视觉主事件提案

状态：`art_proposal / not-produced / not-approved`

**主事件**

> 非人的旧金权柄线把彼此矛盾的历史回廊、星体概念与完整神国折叠到同一条「现在」：帷幕接缝不是人物的背景，而是愚弄与重组发生的法则边界；金线在深色断续处收束而不无限延伸。接缝附近只保留一个微小、无面的身份残影，提示「被看见的角色」与「真正承担后果的主体」仍相关联。

该事件同时服务于：

- 身份：受控文字明确写「序列 0 · 愚者 · 真神」；
- 扮演：折叠位置表达错位中的自我保持（`interpretation`）；
- 能力：愚弄历史造成的相邻状态折叠，并接入星体概念与完整神国；
- 魔药：仅保留安静档案区，不画药瓶与未证材料；
- 晋升：边框成为被跨越又被收束的门槛；
- 限制：金线在帷幕处停止，表达边界与证据缺口。

**构图优先级**

1. 巨大金色权柄线/接缝是唯一主焦点；
2. 由星体、环轨、无尽回廊组成的完整神国作次级结构；
3. 金线在深色断续处停止并回收；
4. 无面身份残影不超过 20% 视觉重量，仅作尺度参照；
5. 上下保留安全文字区，画面不出现可读文字、数字或卡框。

**禁止提前出现的视觉语言**

- 王座、神像、普通脸孔与人物肖像；
- 灰雾之上的人物集会、塔罗会长桌、可辨认同伴；
- 序列 1 灵体之线/秘偶、序列外天赋、其他途径神权；
- 任何文字、数字、配方标签、魔法阵、水印或卡框。

## 6. 关联故事原材料

以下内容是后续故事的结构素材，不是新增或已批准文案；每段应在正式叙事任务中再次核对时间顺序、剧透边界与来源。已批准的 6 条 S00 文案维持原状，本包不修改。

### 6.1 第一段·最初的谎言

愚者先生一开始只是周明瑞为了活下去而建立的安全距离。他让塔罗会成员相信灰雾之上有一位古老神祇，让他们把恐惧、愿望和秘密放到长桌上，而自己躲在神座之后观察每个人的选择。

**材料用途**：身份起点、塔罗会关系、扮演的距离感。
**证据边界**：塔罗会与灰雾属公开身份层；「为了活下去」为解释性叙事。

### 6.2 第二段·谎言获得了责任

塔罗会成员从交换情报开始，逐渐把真正的希望交给愚者先生。克莱恩可以继续假装自己无所不知，也可以承认自己无法解决所有问题。每当有人在灰雾之上呼唤「愚者先生」，那个名字就不再只是伪装，而开始要求他对结果负责。

**材料用途**：扮演反馈、身份从工具变成责任。
**证据边界**：塔罗会互动为剧情定位；「名字开始要求负责」为卡牌叙事转译。

### 6.3 第三段·成为神明的仪式

序列 0 的晋升并没有让过去的身份自动消失。廷根的同事、贝克兰德的朋友、海上的盟友、乌托邦的秘偶和灰雾之上的塔罗会共同构成了他的锚。克莱恩必须在巨大的权柄和无数互相冲突的身份之间完成晋升，真正的困难不是让时间、历史或命运被愚弄，而是被愚弄之后仍然知道自己是谁。

**材料用途**：晋升维度、身份链收束、限制的伏笔。
**证据边界**：晋升仪式为 `verified`；「锚」与身份冲突为角色资料层/解释。

### 6.4 第四段·沉睡之前

当福生玄黄天尊的意志、阿蒙的窥伺和诸神的力量同时压来，克莱恩没有得到一场干净的胜利。他成为愚者，却必须把自己交给漫长的沉睡，继续在梦境与高位意志中争夺主体。神明的故事因此没有结束；它只是从「如何成为神」转成「如何在成为神后仍保有人性」。

**材料用途**：限制、人物内核、与序列 0 边界提案的关系出口。
**证据边界**：沉睡为特定剧情阶段定位（第 1389 章），不等于通用限制；高位意志属角色资料层。

## 10. 研究结论

当前可以安全保留的卡牌核心是：

> **一个以「愚者先生」在灰雾之上承担了神明身份、却用整条身份链作为锚保持自我辨认的克莱恩身份切片；他的真正难题不是愚弄时间、历史或命运，而是在成为神之后仍然知道自己是谁。**

这句话是卡牌原材料的解释性摘要，不是原著固定术语。序列 0 的配方、仪式与三项能力为 `verified`；扮演为明确标注的 `interpretation`；限制为有范围的 `knowledge_gap`。本包没有启动任何 Skill 生产步骤，也没有产生可发布卡牌资产。
