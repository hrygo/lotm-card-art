## 文案边界

本版本共 12 条台词：每张卡 1 条问候语、2 条原创口头语、3 个解释性故事章节。口头语标记为 `original`，故事标记为 `interpretation`；不使用原著逐字引文，不把原创内容冒称正典。故事只写对应身份阶段，不提前借用更高序列能力。

S09 的叙事轴为“先把眼前看清 → 灵摆之外的核验 → 回家之前”；S00 的叙事轴为“陌生名字 → 灰雾之上的长桌 → 风暴与沉睡”。

## 声音合同

- S09 使用 SpeechRail 当前 `/v1/voices` 返回 `available=true` 的系统音色 `dylan`，语气清晰、克制、年轻；
- S00 使用 `available=true` 的系统音色 `uncle_fu`，语气成熟、稳重、从容；
- 不注册自定义音色，不进行声音克隆；
- 每条完整台词单独生成 WAV，应用资源名与 `NarrativeLine.audioResourceName` 一一对应；
- 生成后必须通过真实 WAV 解码、采样格式、时长与 SHA-256 校验，失败则保持文字稿而不宣称配音完成。

## 2026-09-14 追加：代词归一为「祂」

- 依项目约定「**真神及以上**（序列 0 真神、天使之王、旧日/序列之上）的第三人称代词一律用 **祂**」，S00「愚者先生」（序列 0 真神） 卡的文案已把指代该存在的人称代词统一为 **祂**（原为 `他`）。
- **发音说明（记录诚实）**：`祂` 与 `他` 在普通话中同音（`tā`），预期发音不变，因此**本轮没有重出音频、也没有逐条试听**；如要求声画严格对齐，须另行重出并试听。
- 因正文变更，`contentDigest` / `approvedDigest` / `artifacts/lotm.fool.s00/audio-v*/generation.json` 的 `text_digest` 与对应 Swift 叙事文件已同步重算；本轮 `check-fool-audio` 通过。
- **归一范围（用户追加裁定）**：指代**源质与概念**的代词（永暗之河、暗影世界、灾祸之城、母巢、秩序、知识等）**同样用「祂」**；仍用「它/它们」的只有**物体、事件与复数事物**（如世界、两条途径、可能性）。
