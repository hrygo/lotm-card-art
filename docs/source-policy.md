# 设定核验与资料缺口

默认作品范围：第一部中文原著。每条source登记作品、版本、语言、访问范围与定位方式。
第一部中文原著和适用的作者公开说明可支持此范围的断言；英文翻译、续作和改编分别记录，不自动改成中文原著结论。
社区百科和模型记忆用于找线索，不直接使断言变为verified。

断言应尽量单一；记录id、assertion_kind、predicate、value、dimensions、sequences、work_scope、source_refs和verification。
assertion_kind区分canon（作品断言）、interpretation（有依据的解释）和knowledge_gap（经确认的信息缺口）。解释不得承担精确事实，来源访问状态与解释性质分别记录。
`verified`必须有实际核验者、时间和可复核位置，且来源访问范围覆盖所引用段落。字符串填了verified不等于真的读过。
`sequences`列出本断言确实适用的序列，不默认把高序列能力继承给低序列。
配方主/辅材料、进入当前序列的仪式、扮演、能力与限制分开记录；没有完整信息就只做摘要。

角色自己的说法要在scope/notes里注明；若它只是推测，不能作为无条件的世界规则。
精确中文名称须从中文底本核对；译本可帮助定位但不自行回译并宣称正式名称。
某些关键词在多个序列出现时，需检查能力尺度、条件和来源，不能因为名字类似就合并。

## 否定与缺失
确认“未披露”需要可追溯的检索范围、检索记录与审核。没找到不够。
确认“不适用/不需要”需要能支持否定判断的证据。低序列调配程序的描述不可自动推广到所有晋升机制。
可先记录partial并只表达已知材料，不自创缺失部分。上卡时避免暗示自己提供的是完整配方。
没有证据且又无法确认缺口时留在research，不能为了排版完整而造一个仪式。

## 引用与知识产权
保存位置与原创概述，尽量不保存原文；必要短摘录须克制，禁止打包全书或整章。
本包sources中的两段小说网页仅用于展示来源访问状态：第31章可见正文，第57章只取得开头预览。
它们不是已完成的中文底本核验，也没有被自动写入220张卡的canon。
图像素材的来源、授权与可复用状态另在references登记，设定引用不自动授予美术素材使用权。
