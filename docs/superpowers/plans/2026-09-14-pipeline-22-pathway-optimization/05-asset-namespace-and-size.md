# 05 · 资产命名空间与仓库体积治理

> **状态**：Agent 生成提案（非约束、非批准）。父文档：`00-master.md`。优先级 **P2**。依赖：`02`、`03`。

## Goal

让资产布局在 22 途径 × 10 序列的规模下（a）**命名不冲突**、（b）**体积有预算**，同时不破坏「artifacts 不可覆盖」的 provenance 约束。

## 现状证据

| 事实 | 数值 |
|---|---|
| `production/` 文件面 | 295 个 `*.json`，其中 **150 个**文件名含 fool（**51%**） |
| 命名形态 | 扁平 `fool-*.json`（symbols 12、tasks 18、templates 3、schemas 2、calls 18、compositions 5） |
| 每卡存放 | `artifacts/production/<card>-v1/v001/raw.png`（provenance）**与** `apps/LotmCardStudio/Resources/CardArt/<name>.png`（bundle）**各一份** |
| 实测体积 | App Audio 合计 **19M**、CardArt 合计 **16M**（含既有 2 卡）；本轮新卡 artifacts 目录约 **23M** |
| 增长趋势 | tag 时 App 卡图 5 张；打 tag 后工作区已增至 **11 张**（+6） |

**推算**：按现形态，22 途径 × 10 序列若各 1 张序列卡 + 若干人物卡，卡图/音频将以 **两份拷贝** 的方式线性增长，仓库体积将成为现实约束。

## Must Do

- [ ] **T1 命名空间**：`production/symbols/<pathway>/…`、`tasks/<pathway>/…`、`calls/<pathway>/…`、`templates/<pathway>/…`（与 `02-T3` 同批实施，避免两次迁移）。
- [ ] **T2 卡图单一存放**：决定并记录一种方向——
  - (a) 只存 `artifacts/`（provenance），由**构建脚本**拷贝进 App bundle；
  - (b) 保留双份但引入 **Git LFS**；
  - (c) 保留现状，但接受体积并加预算检查。
  三项需**用户决策**（引入 LFS 属新增外部依赖，不擅自决定）。
- [ ] **T3 体积预算与检查**：新增轻量检查——单文件大小上限、每批次新增总量报告；超出即在门禁/CI 提示（不自动阻断，先观察）。
- [ ] **T4 预算测算**：给出 22×10 规模下的体积估算（按每卡卡图 + 6 条音频的实际均值推算），作为 T2 决策依据。
  **实测推算（2026-09-15，`python3 tools/production.py report-asset-size`）**：卡包批次（1 卡图 + 6 WAV）10 个，均值 **3.43 MB**；当前 13 批次合计 **285.17 MB**，最大单文件 **19.65 MB**（`artifacts/lotm.visionary.s07/render-v001/…-collector-v001.png`）。按**单份存放**推算：220 张序列卡 ≈ **0.74 GB**；若每卡另存一次 4K 收藏渲染（按当前最大 19.65 MB 计）另需 ≈ **4.22 GB**。T2 已按 ADR-004 决策 1 实施（只存 `artifacts/**` + 打包期拷贝），因此上表「两份拷贝」线性增长项已消除。

## Must Not Do

- 不迁移/改写 `artifacts/**` 的既有内容（不可覆盖 provenance）；T1 只对**新输出**生效，历史路径由 `02-T4` 的只读映射兼容。
- 不擅自引入 Git LFS 或其他外部依赖（需用户决定）。
- 不删除任何已批准资产。

## 验收标准

- [ ] 新增一条途径时，其资产/任务/合同**不与既有途径命名冲突**（可用合成途径 id 验证）。
- [ ] 体积检查可运行，并能报出「本批次新增 X MB / 最大单文件 Y MB」。
- [ ] 历史 `artifacts/` 路径与回执在迁移后仍可解析（依赖 `02-T4`）。

## 风险与回退

- **风险**：命名空间迁移与并行写入者冲突最大（涉及全目录移动）→ 独占批次。
- **风险**：若选 LFS，历史大文件需迁移，操作重；建议先做 T3/T4 观察，再决定 T2。
- **回退**：迁移批次可整体 revert；新输出路径变更不影响旧产物。

## 工作量估计

T1 **中**（机械但面广）；T3/T4 **小**；T2 取决于用户选择（(a) 中、(b) 大、(c) 小）。
