# 愚者途径五档品质物料重生成设计

状态：待用户审阅
日期：2026-09-13
范围：愚者途径序列 9–0 的五档品质边框、材质、宝石与序列组合物料

## 1. 已确认决策

- 愚者途径序列 9–0 的十枚融合圣徽全部视为用户认可的视觉基线。
- 本轮不保留原四档套件作为当前资产、交付基线或回退方案；历史记录只在依赖审计需要时保留，旧物料不参与新装配。
- 五档视觉映射固定为：低序列 9/8、中序列 7/6/5、圣者 4/3、天使 2/1、真神 0。
- 质量主色只作用于边框纹理、珐琅嵌饰和宝石体色；人物、场景、姓名和圣徽数字骨架不自动染色。
- 五档通过材质深度、受控色相流动、反射和宝石切面区分，不通过增加构件、扩大圣徽或堆叠光晕区分。
- 目标是五套共享品质物料加十张序列对应的独立带徽卡框，不制作无意义的五十种组合。

## 2. 交付物

### 2.1 五套共享品质物料

每一档生成独立材质研究图与可装配材质层：

| 品质 | 序列 | 主色 | 视觉重点 |
| --- | --- | --- | --- |
| 低序列 | 9、8 | 银白 `#E8EDF2` | 克制的雾银、浅槽、低饱和体积感 |
| 中序列 | 7、6、5 | 翡翠绿 `#55B978` | 精抛金属、通透绿珐琅、受控反射 |
| 圣者 | 4、3 | 秘蓝 `#4D97D4` | 深层蓝色晶质、清晰切面、冷光反射 |
| 天使 | 2、1 | 典藏紫 `#A66BD6` | 深紫内蕴、镜面边缘、局部火彩 |
| 真神 | 0 | 橙金 `#F0B23F` | 金色结构、琥珀宝石、完整而克制的高光 |

主色从 `config/quality-color-tokens.json` 读取，表格仅用于说明，不在任务或 Skill 中维护第二份色表。

### 2.2 十张序列物料

将十枚已认可的 9–0 融合圣徽分别装配到对应品质框，产出十张独立透明卡框：

`fool-9-frame`、`fool-8-frame`、`fool-7-frame`、`fool-6-frame`、`fool-5-frame`、`fool-4-frame`、`fool-3-frame`、`fool-2-frame`、`fool-1-frame`、`fool-0-frame`。

每张只使用一个序列数字与一个对应品质，不改变已认可圣徽造型，不复制 9 的接点参数到其他数字。

### 2.3 工程与审阅物料

- 固定几何母框、结构蒙版、纹理区域、宝石区域、圣徽保护区和姓名保护区；
- 十枚圣徽的净底候选、深底/浅底诊断和小尺寸诊断；
- 五档对照图、十张序列接触图、manifest、task、call、receipt 与视觉报告；
- 新五档渲染器及其自测/回归测试。

拼版仅用于审阅，不能代替十张独立 PNG。

## 3. 生产方法

### 3.1 Agentic 材质创作

为五档分别建立结构化任务，实际附上固定母框、愚者双侧帷幕承接结构和已认可圣徽的真实参考图。Agentic 只创作该档的材质语言：纹理起伏、粗糙度、珐琅深度、反射环境与宝石切面；提示中明确禁止重画外轮廓、移动窗口、移动姓名牌、改动圣徽数字和增加装饰构件。

五档分别调用，不使用五档拼版冒充独立原图。每次调用保存真实 prompt、实际附件和返回图像；未知模型参数不伪造。

### 3.2 确定性装配

新增版本化的五档渲染链，读取当前配色和固定几何合同：

1. 以冻结母框为唯一空间基线；
2. 在固定纹理/珐琅/宝石 mask 内应用 Agentic 材质结果或受控材质派生；
3. 保持外轮廓、内窗口、帷幕接点、品质片、姓名牌和所有锚点不变；
4. 将十枚圣徽按其可见字形边界逐枚定位到固定圣徽安全区；
5. 对每张序列卡框输出独立透明层和深底预览。

旧 `foolkit.swift` 的四档逻辑不修改为兼容假五档，也不将旧 `all` 输出改名使用。新渲染器必须显式拒绝缺少 saint/angel 区分的输入。

### 3.3 圣徽处理边界

十枚圣徽的造型认可与工程透明/定位是两个状态：本轮不重新设计已认可造型，但仍逐枚检查真实 alpha、镂空、接点和小尺寸可读性。工程修整不得改变数字骨架；若某枚无法在不改形的前提下净底，则记录为工程缺口，不以伪透明交付。

## 4. 零漂移与材质门禁

- 五档共享同一坐标系、画布、采样、结构 mask 和锚点。
- `max_anchor_drift_px=0`、`max_geometry_drift_px=0`；禁止逐档平移、缩放、旋转、扭曲或用配准隐藏漂移。
- 允许纹理明暗、冷暖和局部色相流动；不允许随机彩虹噪声、整卡染色或相邻档混淆。
- 宝石必须同时保留体色、暗部、内部折射、切面高光和小范围火彩；不接受泛白光团或大面积 bloom 遮挡结构。
- 逐张检查透明边缘、孔洞、帷幕接缝、圣徽实心接点、姓名保护区和品质片；深底、浅底、原尺寸和缩略图均需观察。
- 结构门禁、材质外观、数字回读、品质辨识和用户认可分别记录；机器通过不等于艺术批准或正式 release。

## 5. 文件与版本策略

- 新输出使用新的 `artifacts/production/fool-five-tier-kit-*` 版本目录，不覆盖 `fool-frame-kit-v3` 或任何已有文件。
- 新任务使用显式 `low`、`mid`、`saint`、`angel`、`true-god`，不使用旧 `high` 代替圣者/天使。
- 当前十枚圣徽的认可范围绑定具体文件和摘要；不把本轮认可外推到其他途径或未来新稿。
- 原四档目录先做精确依赖盘点；确认无当前入口后从工作集移出，使用可恢复方式处理，不改写历史回执冒充从未生成。
- 当前新物料均为 `pending`，不自动接入正式 App、不生成音频、不宣称 220 张卡牌完成。

## 6. 验证计划

1. 结构化任务通过 schema 与依赖检查；
2. 新渲染器 selftest 验证五档映射、零漂移拒收、alpha 和宝石高光约束；
3. 五档材质与十张序列物料通过实际 PNG 解码、哈希、尺寸、透明和固定位置检查；
4. 运行愚者物料专项回归与必要的仓库结构检查；
5. 观察五档对照、十张接触图、深浅底诊断和缩略图；
6. 记录已生成、检查通过、待用户视觉确认和未执行项，最后再等待用户批准。

不包含人物主体、角色叙事、声音、App 接入、其他 21 条途径或正式发布。
