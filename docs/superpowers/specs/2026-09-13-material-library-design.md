# 公共物料库 v1 与精细合成 v2

状态：执行方案已由用户“执行”授权；美术资产仍需独立验收。

## 范围
先公共底座，再愚者四档纵向样板；不批量生成22途径、不研究或冒充正式人物卡。
五层目录：公共基础、公共组件、公共层级、途径基础、途径层级。卡片主体不计入公共物料。
复用旧纸纹，新增冷银、暖金、愚者帷幕材质及高序列边缘装饰。四档结构、窗口、姓名承载区采用可编辑矢量/遮罩。十个愚者复合数字保留当前提案状态。

## 接口与回退
保留 tools/production.py 和 compose.swift 原样，保护已有快照。新增 tools/materialctl.py、tools/render/materials.swift，消费已登记 receipt 和带摘要的组件包。
物料包含 id/version/status/scope、锚点、遮罩、合成配方；实际源引用必须绑定 sha256。配方按有序节点组成，可交错栅格和矢量；身份文字最后绘制。
锚点映射为1000×1500设计坐标。遮罩支持rect/ellipse/path、反向孔洞、羽化；混合支持normal/multiply/screen/soft-light；局部亮度、饱和度和接触阴影有明确范围。
非正式物料试装输出仅允许 material-study，不能通过正式release；带姓名的单卡演示仅标概念，不修改来源card.json。换序列的四档板不暗示测试插画符合相应能力。
所有输出新目录；失败非零并保留failure记录；回退只需继续使用未改动v1入口，无迁移、删除或覆盖。

## 检验
输入拒绝未知字段、越界/非有限数、重复id、非法混合、无效锚点。引用与输出摘要绑定。全解码PNG，输出sRGB；实际alpha统计区分透明像素与有alpha通道但全不透明，不自动判定棋盘格。
新增像素级测试：孔洞、羽化、混合、曝光及有序遮挡；中文长名溢出阻断。旧79项测试继续运行。
交付物料清单、组件接口、真实源图、四档试装、旧新对照和黑白彩底诊断图。人工评审检查接缝、光照、名字与复合标识的可读性；机器不冒充艺术评分或用户盲测。
收藏版必须注明栅格重采样，不是原生4K细节。第二途径及其余途径列为后续待制作，不计入本轮完成。
