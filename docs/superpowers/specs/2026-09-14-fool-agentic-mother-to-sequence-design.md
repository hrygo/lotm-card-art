# 愚者途径 Agentic 母版—五档—十序列流水线设计

状态：待用户审阅  
日期：2026-09-14  
范围：愚者途径的边框母版、五档品质边框、十个序列框架物料；不包含人物主体、姓名、口头语、故事、声音或正式卡牌发布。

## 1. 背景与问题

当前流程把母版、品质派生、圣徽装配和文字铭刻混在同一轮生成中，导致以下问题反复出现：

- Agentic 重绘完整边框时会改动外轮廓、柱体、宝石和文字区的位置；
- 生成图可能只有 RGB、没有真实 alpha，或把棋盘格烘焙进图像；
- 姓名区容易被增加一块底板，钻石被遮挡，文字也会出现镜像、重叠或不居中；
- 五档品质被误解为五套独立结构，或者被扩成没有必要的 50 个组合；
- 序列名称如果直接贴字，又会丢失此前已认可的愚者侧柱铭文风格。

此前的低序列到中序列 Agentic 全框迁移测试已经显示：大轮廓和材质创造力可以保留，但输出为 1024×1536 RGB、无 alpha、含烘焙棋盘格，启发式轮廓 IoU 为 0.767128，不能作为生产母框。因此新流程必须明确：Agentic 拥有美术创作权，程序拥有几何、字符、alpha 和交付权。

## 2. 目标与非目标

### 目标

1. 由 Agentic 创作一张具有愚者途径特征的边框母版。
2. 母版一次性固定左侧途径标识、顶部圣徽嵌孔、右侧序列铭刻区、底部姓名区和宝石嵌位。
3. 从同一母版派生低序列、中序列、圣者、天使、真神五档品质边框。
4. 五档只改变材质、受控色相流动、反射和宝石表现，不改变身份几何。
5. 将五档边框按序列层级映射为十个序列框；每个序列只使用一档品质和一枚对应圣徽。
6. 让 Agentic 参与右侧序列名称的艺术铭刻，但把实际字符、位置和最终 alpha 锁在固定局部区域内。
7. 所有中间稿都能作为结构化资产登记、回放、审查和拒收，不能用候选稿冒充正式母版。

### 非目标

- 不把五档与十序列做成 50 张框架组合；
- 不重做已经认可的愚者 0–9 融合圣徽形体；
- 不让 Agentic 生成主体插画内的说明文字；
- 不在本流水线内加入角色姓名、故事、口头语或音频；
- 不因机器门禁通过就自动获得用户视觉批准或正式 release。

## 3. 核心决策

采用四段式流水线：

```text
Agentic 母版创作
        ↓
FrameCore 几何冻结与净底
        ↓
Agentic 五档材质/宝石派生 + 确定性五档落版
        ↓
Agentic 右侧局部铭刻 + 确定性十序列装配
```

关键原则是“艺术派生不等于几何继承”。Agentic 可以提出新的材质、浮雕、反射、宝石切面、铭刻深度和局部装饰语言，但任何候选图都不能通过缩放、旋转、透视、配准或手工平移来伪装成零漂移母版。

## 4. 资产层级与所有权

### 4.1 愚者母版

母版是一套固定的 `FrameCore + EmblemDock + NameSurface + GemSlot` 结构：

- `FrameCore`：外轮廓、两侧柱体、顶部和底部结构、插画窗口；
- 左侧途径标识：具有愚者风格的艺术化途径名称/途径标记，属于路径身份层；
- `EmblemDock`：顶部圣徽嵌孔、暗腔、承托面、接触受光和前缘遮挡；
- 右侧序列区：预留固定的空白铭刻安全区，母版阶段不得出现序列名；
- `NameSurface`：现有材质表面上的姓名区域，母版阶段保持无文字、无新增底色；
- `GemSlot`：姓名区底部中央上方的固定宝石嵌位，母版只定义位置和承接结构，不同时放入五枚宝石。

“五档宝石区域”表示同一固定嵌位的五种品质物料：最终每张序列框只放入与序列品质对应的一枚宝石。

### 4.2 五档品质边框

从同一个冻结母版派生五个共享品质物料：

| 品质 | 序列映射 | 允许变化 |
| --- | --- | --- |
| low | 09、08 | 银白材质、低饱和反射、克制切面 |
| mid | 07、06、05 | 翡翠材质、通透珐琅、受控反射 |
| saint | 04、03 | 秘蓝晶质、明确切面、冷光折射 |
| angel | 02、01 | 典藏紫、深层内蕴、镜面边缘 |
| true-god | 00 | 橙金结构、琥珀宝石、完整而克制的高光 |

实际色值、`hue_drift` 和 `gem_luminance` 必须从 `config/quality-color-tokens.json` 读取。品质差异来自材料品质和光学响应，不来自不断增加的结构数量、放大圣徽或堆叠装饰。

### 4.3 十个序列框

最终框架资产是十个序列变体，而不是五档乘十序列：

```text
五个共享品质 FrameCore
    + 十个序列的固定层级选择
    + 十枚已认可的 0–9 融合圣徽
    + 十个右侧序列名称铭刻
    = 十个序列框架资产
```

十个序列框分别使用 `09、08、07、06、05、04、03、02、01、00`。名称、层级和事实来源从 `pathways/fool` 及对应 `card.json` 编译，不在提示词或 Markdown 中另造事实表。

## 5. 三个 Agentic 创作阶段

### 5.1 阶段 A：Agentic 生成母版

输入必须包括愚者途径方向、既有愚者侧柱风格参考、EmblemDock 结构意图和固定版式要求。提示中明确：

- 左侧必须成为愚者途径身份载体；
- 顶部必须形成圣徽嵌孔和承托结构；
- 右侧序列区必须留白；
- 姓名区必须是现有材质表面，不允许额外底板；
- 宝石位于姓名区下方中央的固定区域，尺寸适中、切面清楚、不可侵入姓名区；
- 不添加序列数字、角色姓名、主体插画或其他解释性文字。

母版 Agentic 图是美术源图。通过净底、区域分割和几何测量后，才能产生生产用 `FrameCore`。若源图没有真实 alpha，必须在登记中注明并完成受控隔离；不能把烘焙棋盘格当作透明。

### 5.2 阶段 B：Agentic 派生五档

以冻结母版作为唯一视觉参考，分别生成五次品质派生研究。每次只要求 Agentic 探索：

- 边框表面纹理、凹凸、粗糙度和金属/珐琅反射；
- 宝石体色、暗部、内部折射、切面高光和局部火彩；
- 愚者侧柱与嵌座之间的材质连续性；
- 该品质对应的克制、尊贵或神性光学语言。

Agentic 的完整五档图是候选研究，不自动成为五档生产框。候选通过视觉筛选后，程序将获选的材质语言应用到冻结几何与固定区域 mask，产出真正可复用的五档 `FrameCore`。因此五档可以保留 Agentic 创造力，同时保持外轮廓和所有接口零漂移。

### 5.3 阶段 C：Agentic 铭刻十个序列名称

每个序列使用所属品质的冻结框，Agentic 只接收右侧铭刻局部区域和愚者侧柱铭文风格参考，不能重新生成整张框。局部研究必须：

- 使用固定方向和固定宽度的右侧铭刻区；
- 以凹刻、倒角、内缘高光和同材质受光表现文字；
- 保留右侧立柱作为唯一底材，不另加胶囊牌、全面板或不透明底色；
- 文字保持正向，不能镜像、伪造、重叠或侵入宝石/姓名/圣徽区；
- 仅在局部产生像素变化，其他区域与冻结框一致。

Agentic 负责铭刻的艺术处理，程序负责精确字符轮廓、实际墨框、上下左右居中、alpha、遮罩和最终合成。若 Agentic 局部稿的字符无法逐字核验，保留其材质/凹刻风格作为候选参考，不把错误文字带入最终资产。

## 6. 确定性合成顺序

每个序列框按以下顺序装配：

```text
FrameCore
  → 品质纹理与珐琅区域
  → GemSlot 对应品质宝石
  → EmblemDock 暗腔/承托/接触阴影/前缘
  → 对应序列融合圣徽
  → 右侧精确序列铭刻
  → 输出透明序列框与诊断图
```

姓名层不在本批次生成；后续角色卡以实际姓名墨框直接铭刻到 `NameSurface`，不带底色，不遮挡宝石。主体背景与人物插画也在后续单卡阶段生成，不能反向修改母版几何。

## 7. 硬门禁

### 母版门禁

- 2:3、目标输出尺寸、sRGB、真实 RGBA；
- 左侧途径标识位于路径身份域；
- 右侧序列区在母版阶段为空；
- 姓名区为空且没有新增背景层；
- 宝石嵌位存在且不侵入姓名区；
- 顶部 EmblemDock 的外框、锚点、保护域和所有权完整；
- 任何生成稿的额外边框、文字或棋盘格像素都不能未经隔离进入 `FrameCore`。

### 五档门禁

- 五档使用同一 `geometry_id`、画布、采样和结构 mask；
- 外轮廓、插画窗口、立柱、EmblemDock、姓名区、宝石位的几何差异为 0；
- `max_anchor_drift_px=0`、`max_geometry_drift_px=0`；
- 只有指定材质域和宝石域发生品质变化；
- 宝石同时具备体色、暗部、切面和光亮，不得变成过曝白团；
- 颜色允许受控色相漂移，不允许整框平涂或相邻品质混淆。

### 十序列门禁

- 每个序列只绑定一个正确品质和一枚正确数字圣徽；
- 右侧铭刻的实际字符必须与结构化输入逐字一致；
- 文字正向、无镜像、无第二层重复字形；
- 实际墨框在右侧安全区内上下左右居中，中心误差不超过 1 final px；
- 右侧安全区外像素与对应冻结品质框一致；
- 圣徽、铭刻、姓名区、宝石区之间的保护域交集为 0；
- 十张序列框全部通过后，状态仍为 `pending-user-visual-approval`，不得自动标记 `approved` 或 `release`。

## 8. 结构化资产与版本边界

实现阶段建立以下版本化入口：

- `production/templates/fool-mother-frame-interface-v1.json`：母版区域、锚点、所有权和保护域；
- `production/schemas/fool-mother-frame.schema.json`：母版机器约束；
- `production/symbols/fool-mother-frame-v1.json`：愚者母版、五档边框和十序列框的资产索引；
- `production/tasks/fool-mother-frame-v1.json`：母版 Agentic 任务；
- `production/tasks/fool-five-tier-frame-batch-v1.json`：五档派生任务；
- `production/tasks/fool-ten-sequence-frame-batch-v1.json`：十序列铭刻与装配任务；
- `production/calls/` 下对应实际 Agentic 调用、附件摘要、观察和门禁记录；
- `artifacts/production/fool-mother-frame-v1/`、`fool-five-tier-frame-v1/`、`fool-ten-sequence-frame-v1/`：分阶段产物。

已认可的 `0–9` 融合圣徽继续作为不可丢弃的视觉基线；它们的工程净底、嵌座适配和实际装配仍分别验收。历史四档工具和漂移稿不作为新流程回退输入。

## 9. 迁移与回退

新版 SOP 作为当前生产入口，旧 `docs/production-sop-v2.md` 保留为历史版本。旧四档框和旧全框 Agentic 迁移稿只保留审计记录；如需清理，必须先做精确依赖盘点并采用可恢复移动。

任何阶段失败时只回退到最近一个已通过机器门禁的结构化阶段：

- 铭刻失败，回退到对应五档框，不重做母版；
- 五档材质失败，回退到冻结母版，不修改 EmblemDock；
- 母版失败，回退到候选研究，不把旧漂移稿提升为母版。

禁止通过后期拉伸、局部涂抹、自由平移或覆盖背景来掩盖失败。

## 10. 验收顺序

1. 先审愚者母版的身份、留白、姓名区和宝石关系；
2. 再审五档并排对照，确认品质差异来自材料而非繁复度；
3. 再审序列 09、07、04、02、00 五个代表档，确认序列区铭刻和五档映射；
4. 最后审十个序列框完整集合、深浅底诊断、缩略图和实际 alpha；
5. 用户视觉确认后，才允许将状态从 `pending-user-visual-approval` 提升为 `approved`。
