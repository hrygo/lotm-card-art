# 途径与序列制作规则

目录顺序是生产组织，不代表原著中的相邻途径、神灵派系或晋升关系。
每个途径十个序列目录；单卡唯一事实源是 `card.json`，不再为每张牌机械复制 AGENTS。
先核对中文名称与序列归属，再研究六维；`canon.json` 只写实际取得依据的断言。
每个维度均需表达计划与回读标准，但不要求统一用文字。工具校验 cue 引用，不代替看图识别。
本序列配方/晋升是进入本序列的要求；当前能力/扮演是成为本序列后的性质。序列 0 也不得随意借用普通低序列配方模板。
继承、新增、强化与外部赐予分开；一个角色持有某物不代表该序列天然拥有同样能力。
`unresearched` 不等于 `not_applicable` / `documented_absence`。数据没填只能是未研究，不能声称原著未披露。
`direction.json` 是原创美术提案不是正典。证据不足可产出研究任务，不把候选意象直接升级成能力事实。
一次完成当前卡的研究、转译、构图、实际图片和审核；不得复制上一张的审核通过状态。
