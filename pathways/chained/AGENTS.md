# 被缚者途径 · 局部设计规则

先读根 `AGENTS.md` 与 `pathways/AGENTS.md`，再读本目录 `direction.json`、`canon.json` 与目标序列 `card.json`。

## 本途径识别
候选主题：内外束缚与自我控制的张力。具体参数在 `direction.json`，不在此重复维护。
对比途径：`hanged-man`、`abyss`——必须给出构图级差异，不能只改配色就复用同一构图。

## 约定与反模式
- 不要把所有序列都画成囚犯绑铁链；束缚必须连接真实语义。
- 不从 `direction.json` 候选意象反推能力；无证据不得把高序列效果提前用到低序列。
- 每个序列至少确定一个独立主事件，让六维线索真正融入卡面，而非文字表格拼贴。
- 途径圣徽无实际批准资产前只能标 proposed，不使用教会圣徽或人物标记假充。
- 若证据推翻当前美术提案，以证据为准并更新方案，不为维护画面扭曲事实。
